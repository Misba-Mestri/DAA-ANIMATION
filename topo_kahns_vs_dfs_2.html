Kahn's Algorithm (BFS)

Iterative. Uses a queue and in-degree array.
Enqueues all nodes with in-degree 0 first.
Cycle detected when |result| < V after queue empties.
Time: O(V+E)   Space: O(V)

DFS Topological Sort

Recursive. Uses visited set + call stack.
Explores each path fully before backtracking.
Prepends node to result on finish. Back-edge = cycle.
Time: O(V+E)   Space: O(V)

Both are O(V+E). Every vertex visited once (O(V)) and every edge traversed once (O(E)). However, Kahn's has lower practical operation & comparison counts: it makes one in-degree comparison per edge and one enqueue/dequeue per vertex. DFS incurs recursion call overhead (push + pop per node), and checks both visited and inStack per neighbour — roughly 2× the comparisons. Same asymptotic complexity, but Kahn's wins on raw operation count for typical DAGs.
